# Security policy

## Supported versions

Security fixes are currently provided for the newest published beta only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or accidental content-access leak.

Use GitHub's private vulnerability reporting for this repository when available. If that option is unavailable, email the maintainer at `jeff@jeffperry.me` with the subject **GPT Ghost Theme security report**.

Include the affected theme and Ghost versions, reproduction steps, impact, and any proof of concept. Do not access data that does not belong to you, disrupt a live publication, or publish details before a fix is available.
